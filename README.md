# Nicola-naka

![layout.jpg](docs/layout.jpg)

親指シフト（Nicola）を、無変換・変換キーのないUSキーボードでも使えるように、**中指同時シフト (+ SandS) 化**したものです。

> [!Note]
> なお、中指同時シフト配列の代表例としては、新下駄配列などがあります。それらと似た感覚で打てるようになっています。
> 
> また、後述する SandS = Space and Shift は薙刀式などでも採用されており、キーボード種類を選ばない親指シフトとして用いられています。**なお、SandSを使うかどうかはオプションです。**

## 設定ファイル

- ＜Windows＞ やまぶきR用
  - [Nicola-naka.yab](Nicola-naka.yab) （**※ UTF-8ではなく、UTF-16LEまたはShift-JISで保存しないと正しく動きません。**）
    - やまぶきRの設定で、**スペースキーを左親指シフトに設定してください。**
      ![screenshot.png](docs/screenshot.png)
- ＜Mac＞ Karbiner-Elements用
  - [Nicola-naka.karabiner.json](Nicola-naka.karabiner.json) (Complex modification用です。説明は割愛します。)
 
## 打ち方

> [!Note]
> 一言でまとめると:
> 
> - :seedling: *非シフト面* → 単打
> - :zap: *濁音*、 :cyclone: *半濁音* → 人差し指シフト
> - :red_car: *シフト面* → 中指シフト or 親指シフト（SandS）
> 
> です。

### 非シフト面

- :seedling: *非シフト面* は親指シフト（Nicola）の定義通りです。単打でそのまま打てます。

### 濁音・半濁音

- :zap: *濁音* は、`F`/`J`（人差し指）と反対側のキーを同時押しです。
  - :information_source: 例えば:
    - `J` + `S` の同時押し → 「`じ`」
    - `F` + `H` の同時押し → 「`ば`」
  - :warning: **【例外】** `J` + `F` の同時押しは「`げ`」で、 「`ど`」を打つには、`J` + `K` もしくは `Q` + `J` の同時押しをします。
- :cyclone: *半濁音* は、`F`（人差し指） と反対側のキーの同時押しです。
  - :information_source: 例えば:
    - `F` + `Y` の同時押し → 「`ぱ`」
    - `F` + `P` の同時押し → 「`ぴ`」

### シフト面

- :red_car: *シフト面* は、`D`/`K`（中指）と反対側のキーの同時押しで打てます。
  - :information_source: 例えば:
    - `D` + `I` の同時押し → 「`る`」
    - `K` + `S` の同時押し → 「`あ`」
  - :warning: **【例外1】** `D` + `J` の同時押しは「`で`」（濁音で既に使われている）なので、 「`お`」を打つには、`J` + `L` もしくは `Z` + `J`、 `J` + `スペース` の同時押しをします。
  - :warning: **【例外2】** `D` + `K` の同時押しは「`な`」で、 「`の`」を打つには、`K` + `L` もしくは `K` + `スペース` の同時押しをします。
  - :warning: **【例外3】** `F` + `K` の同時押しは「`ぎ`」（濁音で既に使われている）なので、 「`ゅ`」を打つには、`D` + `F` もしくは `F` + `スペース`​ の同時押しをします。
- :red_car: *シフト面* は、**SandS（スペースキーによる親指シフト）** でも打てます。
  - 中指同時シフトだけでは打ちにくい  がある際に、左親指シフトをスペースキーに割り当てた上でご利用ください。

## 呼び名
